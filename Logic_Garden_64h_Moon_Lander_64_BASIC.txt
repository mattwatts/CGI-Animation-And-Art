"THE EAGLE [C64 NATIVE]."

The Sovereign Code is compiled into the BASIC Loader below. This script allows you to type the program into your real Commodore 64. It will write the machine code into memory, define the "Gold Spider" sprite, and launch the physics engine.

System Requirements:

    Hardware: Commodore 64 / 128 (in 64 mode).
    Input: Joystick in Port 2.
    Controls: UP (Thrust), LEFT/RIGHT (Lateral RCS).
    Objective: Stick the landing.

THE LESSON: INERTIA

Unlike a video game, you do not stop when you let go of the stick. You must fire against your motion.

INSTRUCTIONS

    Type the code below exactly.
    RUN.
    The screen will clear, physics will initialize.
    Lander is Gold. Thrust turns the engine White.
    1202 ALARM: If the border flashes Purple, you are descending too fast (High Delta-V).

Technical Breakdown (The "Sovereign Code")

Here is the assembly logic used in the machine code above:

    Variables:
        $FB: X Velocity (Sub-pixel)
        $FC: Y Velocity (Sub-pixel) / Gravity Accumulator
        $FD: X Velocity (Whole pixel)
        $FE: Y Velocity (Whole pixel)
    The Physics Loop:
        Gravity: It continually adds +1 to vertical inertia ($FC) every frame.
        Thrust (UP): If Joystick UP is detected, it subtracts 3 from vertical inertia (Net lift of +2). It also changes the Sprite Color to White ($01) to simulate engine burn.
        RCS (LEFT/RIGHT): Adds or subtracts 1 from horizontal inertia $FB.
        Integration: It checks the sign bit of the inertia. If positive, it likely increments the screen position. If negative, it decrements.
    1202 Logic:
        The code checks $FE (Vertical rate). If it exceeds a value of 02 (Fast descent), it pokes $04 (Purple) into $D020 (Border Color), simulating a cockpit alarm.
    Ground:
        Hardcoded floor at vertical position 229. If Y greater than 229, velocity is zeroed (Crash/Land).
